# growth-mindset

成长型心智教练——不只是心理学知识，而是能真正陪你用的心智教练。

收到批评第一反应是防御、说完"我就是不擅长"自己也信了、搞砸了事情反复回放——这些时刻不是你的问题，是思维模式在悄悄运作。这个 skill 让 AI 陪你在这五个场景里练习：

- **情绪处理**：防御反应、反刍思维的觉察与转化
- **思维转化**：固定型 → 成长型的语言与信念重构
- **沟通准备**：带着情绪进入高难度对话前的整理
- **自我探索**：内驱力、价值观、自我关怀
- **成长复盘**：从挫折中提取养分的复盘方法

内置 11 个随手可用的小工具，不需要你说专业词汇，像真正懂你的教练一样主动识别信号、自然引导。配套成长轨迹本地记录（按月归档，支持每日/每周/情绪/里程碑四类），让成长看得见。

理论根基：Carol Dweck 成长型心智、Kristin Neff 自我关怀等公开学术成果。

## 安装

将本仓库整体复制到你的 Agent skills 目录，目录名保持 `growth-mindset`：

```bash
git clone https://github.com/your-name/growth-mindset.git ~/.openclaw/skills/growth-mindset
```

无需任何配置，开箱即用：无网络依赖、无遥测、所有记录保存在本地 `~/.growth-logs/`。
